# 成绩查询（家长扫码查分）

纯静态，零后端。家长扫码 → 输入学生姓名 → 看到自己孩子的成绩。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 家长端（对外，扫码打开的就是这个） |
| `teacher.html` | 教师端工具：Excel 粘贴 → 生成 `data.js`；生成/打印二维码（**不要对外发这个链接**） |
| `data.js` | 成绩数据（base64 编码，需与 `index.html` 同目录） |

## 使用流程

1. 浏览器打开 `teacher.html`
2. 填学校名 / 标题 / 考试名
3. 从 Excel 选中「表头 + 数据」复制，粘贴进文本框 → **解析表格**
   - 表头必须含 `姓名`；可选 `班级` `总分` `班级排名` `年级排名` `评语` `学号`
   - 其余列自动当学科，满分可在下方逐个改
4. 点 **生成 data.js** → **下载 data.js**
5. 用下载的 `data.js` 覆盖本站 `score/data.js`，上传（GitHub Pages 1-2 分钟生效）
6. 回到 `teacher.html` 第二个标签，填本站地址 → 生成二维码 → 投屏 / 打印 A4 海报

## 可选：查询码（推荐开启）

勾选「启用查询码」后，家长必须输入 **姓名 + 查询码**。
- 表格里有 `学号/考号` 列 → 自动取后 4 位
- 没有的话，自己加一列 `查询码`（4 位数字），发给家长

作用：防止有人拿姓名挨个试，把全班成绩翻出来。

## 隐私说明

- 数据做了 base64 编码，手机查看源码看不到明文的整张成绩表（但这不是加密，懂技术的人仍可解码）
- 真要强隐私，用「查询码」模式
- 页面加了 `noindex`，不会被搜索引擎收录
- 连续 5 次查不到会锁 60 秒，防暴力尝试

## 注意

- `teacher.html` 是工具页，**不要**把它的网址发给家长（虽然它不会泄露已生成的数据，但没必要）
- 数据要换考试时，重复第 2~5 步即可，二维码和网址不用变
